# VERSION_LEDGER

Claim ledger for the carrier version axis (`scripts/version_axis_check.py`, criterion P3'): every commit that
touched the contract face, except the newest, must appear on a `COMMITS =` line in this file. Read it when revising
this skill, not when writing a handoff.

<!--
CLAIM_LEDGER =
  COMMITS = 30e9819
  COMMITS = 7b3f31a
  COMMITS = 3d9211a
  COMMITS = dc8dde7
  COMMITS = 94bf5fc
-->
